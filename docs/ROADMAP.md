# 路线图（ROADMAP.md）

> 想法与展望按优先级排列；已实现的移入 `CHANGELOG.md` 对应版本。

## 近期（0.5.x）

- [ ] **解析模板扩充**：更多地区/公司的电、水、燃气账单版式（欢迎提交脱敏样例）
- [ ] **解析自学习**：识别失败时允许用户标注正确字段，沉淀为本地模板规则
- [ ] **网页账单编辑/删除**：看板明细行内直接修改与删除（当前仅设置页可上传录入）
- [ ] **上传附件直接预览**：看板明细点开内嵌 PDF/图片预览，替代新窗口打开

## 中期（0.6+）

- [ ] **提醒与预算**：账单逾期未录提醒、月度预算与超支告警
- [ ] **同比/环比分析**：按费种、按家庭的年度对比图表
- [ ] **导出**：CSV / Excel 导出，腾讯文档同步增强（双向）
- [ ] **移动端适配打磨**：上传与看板的小屏体验

## 远期 / 想法池

- [ ] **多实例聚合**：多个家庭服务器数据汇总到一份总览
- [ ] **OCR 本地化**：接入本地 OCR（如 PaddleOCR）摆脱对视觉模型 API 的依赖
- [ ] **PWA**：离线可用的看板与拍照上传
- [ ] **国际化**：界面英文化（README 已双语）

## 已完成里程碑

- 0.3 双后端（SQLite/MySQL）+ 源码/运行分离 + 一键部署
- 0.4.1 MCP Streamable HTTP（与前端同端口）+ e2e 回归 + 家庭共享 + API Key 自动签发
- 0.5.0 网页上传账单自动识别（PDF 文本层解析 + 视觉模型可选）+ 手工网页录入
